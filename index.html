Billard Spieltage – Kalender-Synchronisation

Immer auf dem neuesten Stand bleiben

Verbinde die Spieltage der Mannschaften mit deinem Kalender. Wähle unten, ob du die Anleitung für Mobil oder Desktop sehen möchtest. Die Links funktionieren in beiden Fällen.

iPhone (Apple Kalender)

  1. Einstellungen öffnen
  2. Nach unten: Kalender
  3. Accounts → Account hinzufügen
  4. Ganz unten Andere
  5. Kalenderabo hinzufügen
  6. Gewünschte Link-URL einfügen (siehe unten)
  7. Weiter → Sichern

Tipp: Der Button „Direkt abonnieren“ öffnet die Kalender-App per webcal://.

Android (Google Kalender)

  1. Im Browser calendar.google.com öffnen
  2. Mit demselben Google-Konto anmelden wie am Smartphone
  3. Links bei Weitere Kalender auf + klicken
  4. Per URL wählen
  5. Gewünschte Link-URL einfügen (siehe unten) → Kalender hinzufügen

Die Termine erscheinen automatisch in der Kalender-App.

Outlook (Windows/Mac) – Abonnieren

  1. Datei → Kontoeinstellungen → Kontoeinstellungen…
  2. Reiter Internetkalender → Neu…
  3. ICS-URL einfügen → Hinzufügen → Namen vergeben → OK

Wichtig „Abonnieren“ ≠ „Importieren“. Nur beim Abo gibt es Auto-Updates.

Windows 10/11 „Kalender“

  1. App öffnen → Einstellungen (Zahnrad)
  2. Konten verwalten → Konto hinzufügen
  3. Abonnieren über Internet (iCal/URL) wählen
  4. ICS-URL einfügen → Speichern

macOS (Apple Kalender am Mac)

  1. Kalender öffnen → Ablage → Neues Kalenderabonnement…
  2. ICS-URL einfügen → Abonnieren → Aktualisierungsintervall wählen

Thunderbird (Lightning)

  1. Kalender → Neuer Kalender → Im Netzwerk
  2. Format: iCalendar (ICS) → ICS-URL einfügen
  3. Namen/Farbe wählen → Weiter
